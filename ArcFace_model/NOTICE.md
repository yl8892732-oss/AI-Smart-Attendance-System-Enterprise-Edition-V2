# ArcFace implementation reference

The TensorFlow ArcFace implementation in this directory is based on
[peteryuX/arcface-tf2](https://github.com/peteryuX/arcface-tf2), specifically
[commit d0d9fc7ada4701001d7c5b233b820d8ee9d35b52](https://github.com/peteryuX/arcface-tf2/commit/d0d9fc7ada4701001d7c5b233b820d8ee9d35b52).

Chenyu Huang used this implementation as the training foundation for the
original face-recognition work. FaceID integrates face matching with employee
enrollment, attendance records, lifecycle management and reporting.

`LICENSE-upstream.txt`.
